# 🦠 COVID-19 Data Exploration — SQL Analysis

## 📌 Overview
An end-to-end data exploration project analyzing global COVID-19 metrics using **SQL Server**. The project explores infection rates, death percentages, and vaccination progress across different countries and continents.

---

## 🛠️ Key SQL Skills & Concepts Applied
* **Joins:** Combining health statistics and population datasets.
* **CTE's (Common Table Expressions):** Structuring complex queries for step-by-step calculation.
* **Temp Tables:** Storing intermediate calculation results for dynamic querying.
* **Window Functions (`PARTITION BY`):** Calculating rolling counts of vaccinated populations.
* **Aggregate Functions:** Summarizing total cases, total deaths, and population infection rates.
* **Creating Views:** Saving database queries for downstream visualization.

---

## 📂 Repository Files
